🔐 Wazuh SIEM SOC Lab

📘 Overview

A complete SOC laboratory built using Wazuh, designed to simulate attacks, monitor Windows/Linux endpoints, and analyze logs in real time.

🧩 Components Used

  • Ubuntu Server 22.04 (Wazuh Manager + Indexer + Dashboard)
  • Windows 10 Endpoint with Wazuh Agent
  • Kali Linux VM for attack simulation
  • VMware Workstation

🛠️ Tasks Performed

  • Full Wazuh installation (manager, indexer, dashboard)
  • Windows and Linux agent configuration
  • Attack simulations (Brute Force, Recon, Malware Test)
  • Log analysis and custom rule creation
  • Dashboarding and alert configuration
