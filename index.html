🤖 Pwnagotchi Build & WiFi Analysis

📌 Project Description

This project involves assembling a Pwnagotchi device and using it to analyze WiFi networks in a controlled and authorized lab environment.

🛠️ Tools & Technologies

  • Raspberry Pi Zero W
  • Pwnagotchi OS
  • Bettercap
  • Linux (Kali / Ubuntu)
  • Balena Etcher
  • SSH

⚙️ Hardware Components

  • Raspberry Pi Zero W
  • MicroSD Card (16GB+ recommended) but used a 32GB
  • OLED Display (Waveshare V3)
  • USB Cable for a laptop connection
  • Portable Battery Pack
  • Header Pins (soldered)

💻 Installation Steps

  1. Downloaded Pwnagotchi image from official repository
  2. Flashed image to MicroSD using Balena Etcher
  3. Configured config.toml file
  4. Inserted SD card into Raspberry Pi
  5. Connected via USB and accessed via SSH

🧠 Configuration

main.name = "payrick_pwnagotchi"
main.lang = "en"
main.whitelist = ["MyWiFi"]
bettercap.handshakes = "/root/handshakes"

🔍 Activity Performed

  • Passive WiFi monitoring
  • Handshake capture (WPA/WPA2)
  • Network signal analysis

📊 Results

  • Captured multiple WPA handshakes
  • Identified nearby networks
  • Analyzed signal strength and encryption types

📚 Sources & References

  • https://pwnagotchi.ai/Official Pwnagotchi Website
  • https://github.com/evilsocket/pwnagotchi" target="_blank">Pwnagotchi GitHub Repository
  • https://www.bettercap.org/

📚 What I Learned

  • How WiFi authentication works
  • Handshake capture process
  • Wireless security basics
  • Embedded Linux device setup
