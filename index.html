💼 Projects

🔐 SOC Lab – Wazuh SIEM

  • The lab environment was built using multiple virtual machines deployed across two different hypervisors. Specifically, VMware was used to create two main virtual machines: an Ubuntu Server instance, acting as the central monitoring and management system, and a Windows 10 machine, configured as the target host.
  • On the Ubuntu Server, the Wazuh Manager was installed and configured to function as a SIEM (Security Information and Event Management) platform. The Wazuh agent was then installed on the Windows 10 machine and successfully connected to the manager. The agent registration and communication were verified both locally on Windows 10 and through the Wazuh dashboard, ensuring that logs and security events were properly collected and visualized.
  • In parallel, a Kali Linux virtual machine was deployed using VirtualBox, serving as the attacker system. Various simulated attacks were launched from Kali Linux against the Windows 10 machine in order to generate security events and test detection capabilities.
  • All malicious activities and intrusion attempts were monitored through the Wazuh platform, allowing for real-time event analysis, log correlation, and the generation of detailed security reports.
