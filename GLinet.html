📡 GL.iNet Security Lab

📘 Overview

A wireless security lab built using GL.iNet routers running OpenWRT, designed for VPN testing, captive portal experiments, and traffic analysis.

🧩 Components Used

  • GL.iNet Mango / Slate / Beryl routers
  • OpenWRT firmware
  • Packages: tcpdump, nmap, hostapd, wpad

🛠️ Tasks Performed

  • OpenWRT firmware flashing
  • Advanced firewall configuration
  • VPN setup (WireGuard/OpenVPN)
  • Traffic analysis using tcpdump
  • Guest network isolation
