🤖 Pwnagotchi Build

📘 Overview

An embedded Linux device based on Raspberry Pi Zero W for passive WiFi monitoring, handshake capture, and wireless security analysis.

🧩 Components Used

  • Raspberry Pi Zero W
  • Waveshare 2.13" e‑ink display
  • 16GB MicroSD card
  • 3D‑printed case
  • 5000mAh powerbank

🛠️ Tasks Performed

  • Pwnagotchi firmware installation
  • Bettercap configuration
  • Plugin setup (auto-update, grid, logs)
  • WPA2 handshake capture testing
  • Packet analysis using Hashcat/Wireshark
